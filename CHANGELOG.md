# Changelog

All notable changes to this conversation-intelligence reference implementation are documented here.

## [1.0.0] — 2026-07-29

- Added a system architecture diagram and a compact evidence index.
- Documented traceability from source deal IDs to monthly aggregates.
- Promoted the deterministic CLI, schema contract and CI-tested report path as the stable release surface.
- Preserved the explicit denominator and causal-interpretation controls across reports.

## [0.1.0] — 2026-07-28

- Added strict structured-output validation for deal-level LLM signals.
- Added traceable monthly aggregation and explicit denominators.
- Added quality flags and causal-interpretation boundaries.
- Added synthetic fixtures, a generated sample report and eight deterministic tests.
- Added Python 3.11/3.12 CI with CLI validation and report-generation smoke tests.
